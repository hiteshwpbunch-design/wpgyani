Connect your WordPress website with a Git repository. Perform Git Pull, Push, Commit, Branch management, and more directly from the admin dashboard.

== Description ==

WP Git Connect is a powerful plugin that brings Git version control directly to your WordPress dashboard.
It allows developers and administrators to seamlessly push, pull, commit, and manage branches.

### Features
* Secure Git commands
* Push and Pull from dashboard
* Branch management
* Backup before pull
* Status checking
* Commit history and diff viewer

== Installation ==

1. Upload the `wp-git-connect` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to **Git Connect** in your admin dashboard.
4. Configure your repository path, default branch, and credentials in the Settings page.
